# 🎉 CricketStream 3.0 (beta)

**The biggest update yet — CricketStream rewritten from the ground up as a single app.**
No Python, no installer, no command windows: download one file, double-click it, and it
sets itself up.

## Download

| | |
|---|---|
| **Windows** | `CricketStream.exe` (Arm laptops: `CricketStream-arm64.exe`) |
| **Mac** | `CricketStream-mac.zip` — Apple Silicon and Intel |
| **Linux** | `CricketStream-linux` — for a scorer's agent or bridge on a spare machine |

Put it in a folder of its own and double-click it. It asks which computer this is — the
streaming laptop or the scorer's — and walks you through the rest.

## What's new

- **One file, its own window.** Setup with a live preview of your stream in your colours,
  then a match-day screen, with the control panel in the same window, already signed in.
- **Seven scorebar styles.** New **Franchise**, **Neon** and **Block** looks inspired by the
  big T20 leagues — and the wicket cards, over summaries and scorecard match the style.
- **Pictures, built in.** Badges, player photos, sponsor logos and match photos are added
  from the control panel's Pictures tab, from the laptop or a phone.
- **Finds your kit.** Discovers the club's IP cameras, installs OBS if it's missing, and
  pairs the scorer's laptop with a short code where the club wifi blocks the automatic search.
- **Keeps an eye out.** A pre-match check of every login and connection on the first screen,
  and Windows notifications if the scorer's feed goes quiet or OBS crashes mid-match.
- **Updates itself.** One click installs a new version, checked before it replaces
  anything. Settings → Export moves the whole club setup to another laptop in one file.
- **A control panel that's yours.** The club's badge and name at the top, and tiles you can
  drag into your own order.

Everything the graphics did in v2.12 still works the same — the overlay, replays, AI
commentary, the result card and match page. The full list is in the
[changelog](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/blob/main/CHANGELOG.md).

## It's a beta

3.0 has been tested end to end — on a clean Windows 11 machine and against a real OBS —
but not yet through a season of real matches. Rehearse with **Match day → Practice match**
before your first stream. The proven **v2.12** (the Python edition) stays available on the
[`python` branch](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/tree/python)
and its release.

Found something? Tell us on [Discord](https://discord.gg/2nuBPj9rH7) or open an
[issue](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/issues) — the Activity
log (`logs/` beside the app) says what happened.
