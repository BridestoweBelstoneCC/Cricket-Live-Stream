# CricketStream 3.0 beta 7 — first ball and final result

**Fixes from a practice match.** The graphics now clear for the first ball of each innings, and
a chase that's won has its result on screen. If you're on an earlier beta, update before your
next match.

## Download

| | |
|---|---|
| **Windows** | `CricketStream.exe` (Arm laptops: `CricketStream-arm64.exe`) |
| **Mac** | `CricketStream-mac.zip` (Apple Silicon and Intel) |
| **Linux** | `CricketStream-linux` (for a scorer's agent or bridge) |
| **Clubhouse screen** | `CricketStream-clubhouse-pi.img.xz` (Raspberry Pi 4 or 5; flash with Raspberry Pi Imager) |

Already on an earlier beta? The app offers the update itself: one click, and it checks the
new version before replacing anything. A clubhouse screen updates itself the next time it
starts.

## What's changed

- **Graphics clear for the first ball.** The pre-match show and the innings break now end when
  the scorer names the openers, not once the first ball is scored, and anything they still had
  queued is dropped. A first-ball boundary no longer happens under the graphics, or during a
  break clip. The finished innings' scorecard no longer comes back 4 seconds into the reply.
- **The end of the match has its graphics.** A side reaching its target with overs left used to
  get no post-match graphics. Now any finished chase shows the result ("Rival CC won by 6
  wickets", "Home CC won by 12 runs", "Match tied"), the innings summary and the final scorecard.
- **The innings summary is filled in on NV Play.** Top scorer, best bowling and extras now come
  from the scorecard.
- **Fixed: an old score after a practice match.** The scorer's old file looked new for 12 hours
  after a practice, so last match's score could go back on the scorebar.
- **Practice match names the openers before the first ball,** as a real scorer does, so it
  rehearses all of this, and a first-ball four gets its replay.

## Still a beta

- If your scorer names the openers long before play, the innings break's graphics stop at that
  moment. If they name them only as the ball's bowled, a first-ball boundary can still be
  covered, though its replay still plays. Neither has been tried on a real match's NV Play feed.
- The result assumes a side of eleven, so "won by N wickets" counts from ten wickets. A
  rain-reduced match shows a result only if the target's reached or the side is all out.
- If the scorer gives only a surname, no XI is entered on PlayCricket and the player's shirt
  number isn't in the **Squad Roster**, the card still shows the record for that surname. Keep
  the roster filled in if you have relatives in the side.
- Commentary hasn't been tried on an Android phone or on a ground's wifi.
- Rehearse with **Match day → Practice match** before your first stream. The proven **v2.12**
  (the Python edition) stays available on the
  [`python` branch](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/tree/python).
