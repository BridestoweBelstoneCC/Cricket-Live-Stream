# CricketStream 3.0 beta 12 — clubs together on the Stats tab

**Clubs added together on the clubhouse screen's Stats tab, and three refinements to beta
11's handling of the internet dropping out.** Nothing else has changed since beta 11;
[its notes](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/releases/tag/v3.0.0-beta.11)
still apply.

## Download

| | |
|---|---|
| **Windows** | `CricketStream.exe` (Arm laptops: `CricketStream-arm64.exe`) |
| **Mac** | `CricketStream-mac.zip` (Apple Silicon and Intel) |
| **Linux** | `CricketStream-linux` (for a scorer's agent or bridge) |
| **Clubhouse screen** | `CricketStream-clubhouse-pi.img.xz` (Raspberry Pi 4 or 5; flash with Raspberry Pi Imager) |

The laptop offers the update in its window: one click.

**The clubhouse screen:** on beta 11 it updates itself. Press **Update the screen** on the
laptop's match-day screen (the *Clubhouse screen* card), or **Check for an update** in the
screen's own settings; left alone, it also checks once a day. A screen still on beta 10 or
earlier needs one restart of its program with the wifi up: see
[beta 11's notes](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/releases/tag/v3.0.0-beta.11).

## New

- **Clubs together on the Stats tab.** The club buttons now add clubs together instead of
  choosing one: the club itself is on to start with, and a tap adds or takes away a former
  club, so a player's whole record (the merged club's and Bridestowe's, say) can be seen at
  once. One club is always on.

## Changed

- **The stream is restarted only once the line has answered twice running**, 5 seconds
  apart, so a line that flickers up for a moment doesn't get a restart into nothing.
- **With OBS on another computer** (`manage_obs = no`), the internet dropping out is only
  reported: CricketStream doesn't record there or restart its stream.
- **The backup recording is stopped first when match day stops.**
