# CricketStream 3.0 beta 9 — club stats, junior mode, and a security review

**The club's whole record on the clubhouse screen, five new match-day features, and the fixes
from an outside security review of the code.** If you're on an earlier beta, update before
your next match, and read "Before your next match" below.

## Download

| | |
|---|---|
| **Windows** | `CricketStream.exe` (Arm laptops: `CricketStream-arm64.exe`) |
| **Mac** | `CricketStream-mac.zip` (Apple Silicon and Intel) |
| **Linux** | `CricketStream-linux` (for a scorer's agent or bridge) |
| **Clubhouse screen** | `CricketStream-clubhouse-pi.img.xz` (Raspberry Pi 4 or 5; flash with Raspberry Pi Imager) |

Already on an earlier beta? The app offers the update itself: one click, and it checks the
new version before replacing anything. A clubhouse screen updates itself the next time it
starts.

## What's new

- **Club stats on the clubhouse screen.** A **Stats** tab: every player's record for the club
  from PlayCricket, as far back as it goes. Filter by club (including the clubs a merged club
  was formed from) and by men's, ladies' and junior cricket, rank by games, runs, wickets or
  catches, and find yourself on the screen's own keyboard. It's there with the laptop off: the
  screen keeps its own copy, refreshed weekly. Update the laptop too: it's where they come from.
- **Your own tabs on the clubhouse screen.** A page of the club's own (a quiz, a darts scorer)
  can be a tab, kept on the Pi only. See CLUBHOUSE_SCREEN.md.
- **Junior match mode.** For an age-group fixture, every player is shown as **Patrick E** on the
  stream, the scorecard, the match page, the report and the chapters, and player cards, photos,
  club records and AI commentary are off. It switches on by itself for an age-group fixture:
  check it before going live.
- **A warning when the stream goes silent or a camera freezes**, in the panel, the clubhouse
  screen, a notification and Discord. On by default; it only warns.
- **The chase at the end of each over:** "Need 48 from 36 balls · 8.00 an over".
- **Hold the graphics back** to match a camera that runs late (off by default).
- **Start match day by itself** before today's fixture (off by default). It never goes live by
  itself.

## Fixed: the security review

An outside read of the code found ways a device on the club's network, or a web page open on the
streaming laptop, could reach things it shouldn't. None is known to have been used. All are
fixed; CHANGELOG.md has each one.

## Before your next match

- **The club password is now kept scrambled in `config.ini`.** It works as before. If you forget
  it, type a new one after `club_password =` in `config.ini` and restart.
- **If you open the control panel through your own web address or a reverse proxy**, add that
  name to `[Network] extra_hosts` in `config.ini`, or it's refused.
- **A tool of your own that read `/live`** must read `/live/view`, and one that made the AI
  report with `GET /report/generate` must use `POST`.
- Thirty wrong passwords from any devices stop new sign-ins from other devices for five minutes.

## Still a beta

- Junior names, the silence warning and the scheduled start have been tested, but not yet on a
  real match day. Nor has the stats tab on a real Pi.
- The catch milestone reads NV Play's last-wicket fields, which haven't been seen on a real
  match's feed yet.
- Commentary hasn't been tried on an Android phone or on a ground's wifi.
- Rehearse with **Match day → Practice match** before your first stream. The proven **v2.12**
  (the Python edition) stays available on the
  [`python` branch](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/tree/python).
