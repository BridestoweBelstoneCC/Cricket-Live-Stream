# CricketStream 3.0 beta 6 — keeping relatives apart

**A fix for clubs with families in the side.** Beta 5's new club appearances and club
milestones could credit a long-serving player's record to a relative with the same surname.
If you're on beta 5, update before your next match.

## Download

| | |
|---|---|
| **Windows** | `CricketStream.exe` (Arm laptops: `CricketStream-arm64.exe`) |
| **Mac** | `CricketStream-mac.zip` (Apple Silicon and Intel) |
| **Linux** | `CricketStream-linux` (for a scorer's agent or bridge) |
| **Clubhouse screen** | `CricketStream-clubhouse-pi.img.xz` (Raspberry Pi 4 or 5; flash with Raspberry Pi Imager) |

Already on an earlier beta? The app offers the update itself: one click, and it checks the
new version before replacing anything. A clubhouse screen updates itself the next time it
starts.

## What's changed

- **Fixed: a relative's record on the player card.** A player whose surname matched a
  long-serving player's could be shown that player's appearances and get their club
  milestones, even when the squad roster gave their full name. Now a first name has to fit,
  and a bare surname is checked against today's XIs when they're known.
- **Relatives are harder to mix up.** "C Smith" no longer joins Charles Smith if a Chris Smith
  is on the club's team lists, and names like Sam and Samantha no longer count as one person.
- **Tell it who's who.** `same_players` under `[Club]` in config.ini names players PlayCricket
  has under more than one name, and every name then finds the one record:

  ```
  same_players = Ian Smith: I Smith, Iain Smith | Matt Jones: Matthew Jones
  ```

## Still a beta

- If the scorer gives only a surname, no XI is entered on PlayCricket and the player's shirt
  number isn't in the **Squad Roster**, the card still shows the record for that surname. Keep
  the roster filled in if you have relatives in the side.
- The new player card hasn't been watched in real OBS yet. Commentary hasn't been tried on an
  Android phone or on a ground's wifi.
- Rehearse with **Match day → Practice match** before your first stream. The proven **v2.12**
  (the Python edition) stays available on the
  [`python` branch](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/tree/python).
