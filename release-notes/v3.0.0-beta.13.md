# CricketStream 3.0 beta 13 — the clubhouse screen follows the laptop

**The clubhouse screen now updates itself when the laptop does.** Nothing else has changed
since beta 12; [its notes](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/releases/tag/v3.0.0-beta.12)
and [beta 11's](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/releases/tag/v3.0.0-beta.11)
still apply.

## Download

| | |
|---|---|
| **Windows** | `CricketStream.exe` (Arm laptops: `CricketStream-arm64.exe`) |
| **Mac** | `CricketStream-mac.zip` (Apple Silicon and Intel) |
| **Linux** | `CricketStream-linux` (for a scorer's agent or bridge) |
| **Clubhouse screen** | `CricketStream-clubhouse-pi.img.xz` (Raspberry Pi 4 or 5; flash with Raspberry Pi Imager) |

The laptop offers the update in its window: one click.

**The clubhouse screen:** on beta 11 or 12 it updates itself (see below), or press
**Update the screen** on the laptop's match-day screen. A screen still on beta 10 or
earlier needs one restart of its program with the wifi up: see
[beta 11's notes](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/releases/tag/v3.0.0-beta.11).

## New

- **The clubhouse screen follows the laptop.** When the screen sees the streaming laptop on
  a newer version, it updates itself at the next quiet moment (match day not running,
  nobody touching it), so updating the laptop brings the screen along with nobody pressing
  anything. **Update the screen** on the laptop and **Check for an update** on the screen
  still do it straight away.

## Changed

- **A screen that couldn't reach the internet when it checked tries again every 15
  minutes**, instead of the next day. That's usually the check at start-up, when a Pi
  switched on at the plug is still joining the wifi.
