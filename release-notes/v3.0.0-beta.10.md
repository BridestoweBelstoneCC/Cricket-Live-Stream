# CricketStream 3.0 beta 10 — drag to scroll on the clubhouse screen

**One fix for the clubhouse screen, found on the first real Pi running beta 9.** Nothing else
has changed since beta 9; [its notes](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/releases/tag/v3.0.0-beta.9)
still apply.

## Download

| | |
|---|---|
| **Windows** | `CricketStream.exe` (Arm laptops: `CricketStream-arm64.exe`) |
| **Mac** | `CricketStream-mac.zip` (Apple Silicon and Intel) |
| **Linux** | `CricketStream-linux` (for a scorer's agent or bridge) |
| **Clubhouse screen** | `CricketStream-clubhouse-pi.img.xz` (Raspberry Pi 4 or 5; flash with Raspberry Pi Imager) |

A clubhouse screen updates itself the next time it starts. The laptop offers the update in
its window: one click.

## Fixed

- **Drag to scroll on the clubhouse screen.** The Stats tab's list, and every other long page
  on the screen, now scrolls by dragging a finger over it, and a flick carries on. On a real
  Pi the touch screen reached the browser as a mouse, which can't scroll by dragging, so the
  only way down the list was the scroll bar. Dragging over a player never opens their card;
  a tap still does.
