# CricketStream 3.0 beta 11 — when the internet drops out

**A stream that copes with the internet dropping out, a backup recording of the whole
match, Off for rain and Drinks on the clubhouse screen, and fixes from a practice match on
beta 10.** Nothing else has changed since beta 10;
[beta 9's notes](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/releases/tag/v3.0.0-beta.9)
still apply.

## Download

| | |
|---|---|
| **Windows** | `CricketStream.exe` (Arm laptops: `CricketStream-arm64.exe`) |
| **Mac** | `CricketStream-mac.zip` (Apple Silicon and Intel) |
| **Linux** | `CricketStream-linux` (for a scorer's agent or bridge) |
| **Clubhouse screen** | `CricketStream-clubhouse-pi.img.xz` (Raspberry Pi 4 or 5; flash with Raspberry Pi Imager) |

The laptop offers the update in its window: one click.

**A clubhouse screen on beta 10 or earlier** checks for an update only once, as it starts,
and a Pi switched on at the plug starts before its wifi has joined. To get beta 11 onto it,
let it start, wait until it's on the wifi, then switch it off and on again (or restart it
from a keyboard). From beta 11 on, it waits for the wifi itself, and the laptop can update it.

## When the internet drops out

- **Back on air within seconds when the internet comes back.** OBS reconnects by itself,
  but waits longer after every try (up to 15 minutes between tries): after a ten-minute
  outage it could sit for another four or five minutes with the internet long since back.
  Now the stream is restarted the moment YouTube's server answers again. Never before then
  (a restart with the line still down makes OBS give up), and not when OBS is signed in to
  YouTube with "Connect account", where stopping the stream ends the broadcast: if that's
  how you stream, use a stream key instead (YouTube Studio → copy the stream key → OBS
  Settings → Stream).
- **A backup recording of the whole match, on by default.** OBS records the match on the
  streaming laptop as well as streaming it, so whatever the internet lost still exists:
  upload it afterwards. It's in `match-recordings` inside your replay folder, and costs disk
  space (1–3 GB an hour), not processing power: it shares the stream's encoding. When the
  drive gets low, the oldest recordings go, never today's. The pre-match check shows how
  many hours there's room for. Switch it off in **Match day → Stream quality**.
- **The window says when the internet has dropped** (after 30 seconds) and when it's back,
  and so does Discord if it's set up. The control panel's stream card shows how long OBS has
  been reconnecting.

## New

- **Off for rain and Drinks on the clubhouse screen**, on the Get ready tab, for when the
  break didn't start by itself. The stream shows the break card, the scorecard, the season's
  stats and the best replays so far (and the rain radar for rain) until the next ball, or
  until the same button is pressed again. The control panel's Breaks card has a **Drinks**
  button too.
- **See and update the clubhouse screen's version from the laptop.** The match-day screen's
  *Clubhouse screen* card shows the screen's version, and when it's behind there's **Update
  the screen**: every screen that's on picks it up within a few seconds, updates and restarts.
  The pre-match check shows a ⚠ for a screen older than the laptop.
- **Check for an update on the screen itself**, in its settings. A screen left on also checks
  once a day by itself, never during match day and only when nobody has touched it for ten
  minutes.

## Fixed

- **Over summaries in the second innings.** At the change of innings the overlay didn't
  forget the last over it had summed up, so in the chase every over up to the first
  innings' length was treated as already shown: no over summary, and nothing that comes
  with it (the AI commentary line, partnership, run rate, win predictor). In a real match
  that's most of the chase.
- **No "scorer's feed has gone quiet" after a practice match.** The practice's own feed
  counted as the scorer's, so two minutes after a rehearsal ended the window (and Discord, if
  it's set up) said the feed had gone quiet.
- **The clubhouse screen updates itself after being switched on at the plug.** It now keeps
  asking for up to a minute and a half while GitHub can't be reached, and writes what
  happened to `~/cricketstream/clubhouse.log` either way.

## Not yet seen for real

Tested on a portable OBS with a simulated line (a ten-minute outage and a line that keeps
dropping), not yet on a real ground's internet or a real YouTube stream. The new clubhouse
buttons haven't been on a real Pi's screen yet.
