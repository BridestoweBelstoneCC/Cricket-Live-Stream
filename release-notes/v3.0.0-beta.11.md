# CricketStream 3.0 beta 11 — the second innings, and keeping the clubhouse screen up to date

**Fixes from a practice match on beta 10, and a better way to keep the clubhouse screen up
to date.** Nothing else has changed since beta 10;
[beta 9's notes](https://github.com/BridestoweBelstoneCC/Cricket-Live-Stream/releases/tag/v3.0.0-beta.9)
still apply.

## Download

| | |
|---|---|
| **Windows** | `CricketStream.exe` (Arm laptops: `CricketStream-arm64.exe`) |
| **Mac** | `CricketStream-mac.zip` (Apple Silicon and Intel) |
| **Linux** | `CricketStream-linux` (for a scorer's agent or bridge) |
| **Clubhouse screen** | `CricketStream-clubhouse-pi.img.xz` (Raspberry Pi 4 or 5; flash with Raspberry Pi Imager) |

The laptop offers the update in its window: one click.

**A clubhouse screen on beta 10 or earlier** checks for an update only once, as it starts,
and a Pi switched on at the plug starts before its wifi has joined. To get beta 11 onto it,
let it start, wait until it's on the wifi, then switch it off and on again (or restart it
from a keyboard). From beta 11 on, it waits for the wifi itself, and the laptop can update it.

## Fixed

- **Over summaries in the second innings.** The overlay never reset the last over it had
  summed up at the change of innings, so in the chase every over up to the first innings'
  length was treated as already shown: no over summary, and nothing that comes with it (the
  AI commentary line, partnership, run rate, win predictor). In a real match that's most of
  the chase. A new test plays a whole simulated match through the overlay's own code and
  checks both innings.
- **No "scorer's feed has gone quiet" after a practice match.** The practice's own feed
  counted as the scorer's, so two minutes after a rehearsal ended the window (and Discord, if
  it's set up) said the feed had gone quiet. A practice is now its own feed.
- **The clubhouse screen updates itself after being switched on at the plug.** It now keeps
  asking for up to a minute and a half while GitHub can't be reached, and writes what
  happened to `~/cricketstream/clubhouse.log` either way.

## New

- **See and update the clubhouse screen's version from the laptop.** The match-day screen's
  *Clubhouse screen* card shows the screen's version, and when it's behind there's **Update
  the screen**: every screen that's on picks it up within a few seconds, updates and restarts.
  The pre-match check shows a ⚠ for a screen older than the laptop.
- **Check for an update on the screen itself**, in its settings. A screen left on also checks
  once a day by itself, never during match day and only when nobody has touched it for ten
  minutes.
